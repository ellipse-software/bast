---
title: First launch
description: What Bast shows the first time you open the TUI with no hosts, and how to skip it.
---

If this machine has no SSH hosts yet, the first TUI launch is the Bast logo, the slogan, and a short welcome. Any key closes it onto Hosts, on the first history suggestion when one exists.

If `~/.ssh/config` already has hosts, Bast opens the picker. History suggestions still appear in the list.

## Keys

Any key continues to Hosts. `Ctrl+C` still quits without dismissing, so the welcome can return next launch.

## When it appears

Only the interactive TUI (`bast` or `bast tui`), and only when discover finds no hosts. Direct connects (`bast <label>`), CLI commands, and `--json` never show it.

Upgrading an existing install does not show it. A machine that already has hosts is marked done without the overlay.

Press `v` (About), then `o`, to show the chooser again without changing first-run eligibility.

## Skip from the environment

```sh
BAST_NO_ONBOARDING=1 bast
```

Useful for screenshots and non-interactive terminals that still attach a TTY.

## After you skip

Empty Hosts and Keys tabs use the same seal language as an unlinked Vault: a fact, not a keybinding lecture. Press `/` for the actions that apply. SSH destinations from history stay in the collapsible **(Suggested)** group. See [Import from shell history](/docs/features/history-import).
